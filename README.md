# StarCards

StarCards is an educational technology platform that transforms PDF materials into Anki study decks.

## What it does

- Ingests PDF documents
- Organizes content using bookmark structure
- Supports multiple card formats
- Exports decks as `.apkg` files for manual import into Anki

## Architecture

StarCards is organized as a modular pipeline with separate layers for ingestion, preprocessing, card generation, export, user interface, provider integration, and orchestration.

The core generation pipeline and prompt architecture are proprietary and not included in this repository.
For institutional licensing or deployment inquiries, please contact the maintainers.
